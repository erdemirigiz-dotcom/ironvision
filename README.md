# ironvisiontools.com

Source of the IronVision Tools website, served by GitHub Pages at
**[ironvisiontools.com](https://ironvisiontools.com)**.

IronVision Tools builds practical software and AI tools — MoyMote for monitor
control, appointment bots, fast business websites, and automation that a shop
owner can actually operate.

## What is in here

| Path | What it is |
| --- | --- |
| `index.html`, `en/index.html` | Landing page in Turkish and English: products, how we work, demo request |
| `vitrin/` | 11 live demo business sites + the [showcase hub](https://ironvisiontools.com/vitrin/vitrin-hub/) |
| `iletisim.html` | Contact |
| `gizlilik.html`, `gizlilik-politikasi-lav.html`, `hesap-silme-lav.html` | Privacy policies and account-deletion page required by the app stores / Meta |
| `assets/`, `js/` | Images, fonts, and the small amount of JavaScript the site uses |

## How it is built

Hand-written static HTML with Tailwind classes compiled into a single stylesheet.
No build server, no framework, no tracking scripts. A push to `main` publishes the
site; the `CNAME` file holds the custom domain.

## Products shown here

- **MoyMote** — Windows app that controls an external monitor from the PC or a phone ([moymote.com](https://moymote.com))
- **AIrandevu** — WhatsApp appointment bot for barbers and hair salons (pilot)
- **Website showcase** — static business sites produced from a shared template set
- **VYRON AgentOS** — automation system (task board, watchdogs, scheduled jobs)
- **Sesli Şef** — voice interface for terminal-based AI agents
