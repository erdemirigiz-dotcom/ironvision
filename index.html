Sıkça Sorulan Sorular (SSS)

Kripto karı nasıl hesaplanır?

Sistem, girdiğiniz yatırım miktarını alış fiyatına bölerek token adedini bulur. Ardından bu adedi güncel satış fiyatıyla çarparak brüt karınızı ortaya çıkarır. API üzerinden canlı kur çekilir.

Kripto varlıklarda vergi kesintisi nedir?

Özellikle ABD ve Avrupa'da (ve gelecekte Türkiye'de), kriptoyu cüzdanınızda tutma sürenize (1 yıldan az veya çok) göre farklı vergi dilimleri (Kısa Vadeli / Uzun Vadeli Sermaye Kazancı) uygulanır. Aracımız bu senaryoları simüle eder.
